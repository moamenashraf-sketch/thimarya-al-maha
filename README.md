# Al Maha Community — Thimarya landing page

Static bilingual (EN/AR) landing page for [Al Maha Community, West Riyadh](https://www.thimarya.sa/en/our-projects/al-maha-community/), built with the Jadeite v2 design system (hero, concept, highlight cards, hairline feature grid, explorer, location, stats, gallery, lead form).

- `index.html` + `style.css` — no build step
- `thank-you.html` — post-submit page with conversion-pixel placeholder
- Content and images are from the existing Thimarya page; Arabic text is a translation and should be reviewed.
